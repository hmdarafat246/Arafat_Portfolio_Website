# Arafat Hossain — Personal Portfolio Website

A responsive portfolio inspired by the screenshot you shared. Built with separate HTML, CSS and JavaScript files.

## How to run
1. Extract the ZIP file.
2. Open the `arafat_portfolio_website` folder in VS Code.
3. Open `index.html` in a browser, or install the **Live Server** VS Code extension and choose **Open with Live Server**.

## Personalize before publishing
- Search for `Arafat Hossain` in `index.html` and change it if needed.
- Replace `assets/profile.jpg` reference in the hero placeholder by adding your photo and updating the markup in `index.html`.
- Update GitHub, LinkedIn and Facebook links.
- Replace `hello@example.com` in both `index.html` and `script.js` with your real email.
- Update the sample education timeline, skill levels and project cards with your real information.
- Add your actual project URLs to each project card.

## Publish free
You can deploy the folder using Netlify or Vercel. For Netlify, sign in and drag the extracted website folder into the manual deploy area. For Vercel, import a GitHub repository containing these files.

## Important
The contact form opens the visitor's default email app; it does not send or save messages through a server. A real backend or form service is needed for server-based submissions.
